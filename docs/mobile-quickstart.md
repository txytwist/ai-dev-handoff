# 每天在手机上操作

1. **ChatGPT 提想法**：打开项目对话，说“请读取项目规范，我想做……，先给最小方案和验收标准”。看懂后明确批准。让 ChatGPT 优先创建项目 Issue；不能写则复制完整任务。
2. **Codex 执行**：打开 Cloud Codex，选择正确项目，粘贴 [执行指令](../CODEX_SETUP.md)。先确认它读到了正确任务；读不到就提供全文。等待 PR 与 Handoff。
3. **ChatGPT 审核**：主动返回，粘贴 [审核请求](../CHATGPT_SETUP.md) 并附 PR、提交与交接。查看问题与证据，明确说“接受”或“按这些问题修改”。新需求重新规划。

不要在不理解时批准。PR 是变更提案，未合并前默认分支通常不会包含新功能。接受结果不自动合并；需要时再单独决定。首次使用看 [初始化](../START_HERE.md)，完整演示看 [示例](../examples/complete-cycle.md)。
