## Public Beta 持续验收

框架已公开；许可证未确定，实机验收未完成。下列视觉检查初始全部为 NOT_RUN，由用户在自己的真实 iPhone上查看实际 GitHub页面后提供反馈，Codex不能用本地模拟替勾。

- **NOT_RUN** 首页不必横向滚动就能找到“复制完整引导”和“逐步设置”。
- **NOT_RUN** 中英文角色短段文字可读，无宽表挤压。
- **NOT_RUN** 两张 Mermaid的节点、字和箭头可见；如难读可用紧随其后的文字版。
- **NOT_RUN** 中文/English链接可切换，入口仍清楚。
- **NOT_RUN** 公开引导页的唯一文本块可完整复制到 ChatGPT，无需向所有者索取。
- **NOT_RUN** 分别在 GitHub App 与移动浏览器打开，记录渲染/复制/滚动差异；未安装 App则记未测。

反馈最少包含：iPhone型号、iOS/浏览器或 App版本、公开页面链接/ref、哪项通过/失败/阻塞、问题位置；截图先脱敏。不能将“已 Public”当成以上实测通过。

新/旧项目端到端表的未实测状态继续保留；另需持续隐私复核与许可归属确认，Public可读不等于开源授权。
