# 所有者 Public Beta 开放步骤

这是准备说明，不是合并、公开或许可证授权。最近核实（2026-11-20）仓库仍 Private。Public 后为可读测试版；LICENSE_PENDING 保留，公开不自动授予许可。

## 合并前审核

1. ChatGPT审查本 PR、Handoff、CI，以及隐私检查发现/限制。历史提交含作者元数据，所有者需决定是否接受暴露；不能以模式扫描通过当作全历史安全证明。
2. 人工复核 Git 文件及 GitHub 非 Git 内容：Issue、PR、评论、附件、Actions 日志/artifacts、仓库描述和设置。脚本没有覆盖所有这些对象；对未知内容保留风险判断。
3. 所有者决定接受或返工，并单独决定是否合并。未合并前不要把默认分支入口当作已经更新。

## 用户决定合并后，在手机操作

1. 手机浏览器打开 https://github.com/txytwist/ai-dev-handoff ，确认默认分支已含本 PR、隐私风险已接受。
2. 只有你已决定公开时，进入 GitHub **Settings → General → Danger Zone → Change repository visibility → Public**，阅读提示并完成 GitHub要求的确认。界面可能不同，需仓库管理员权限；找不到可用移动浏览器桌面站点视图。本文及开发工具不会自动切换可见性。
3. 用未登录/无私有授权的手机会话打开仓库首页，检查 README、START_HERE、引导全文和外部 AI 提示可读。失败就记录阻塞，不能声称已开放成功。
4. 复制外部 AI 提示发给评审者，按反馈模板收集结果，区分模拟与实机；不要向其提供真实项目秘密。
5. 更新状态记录为“Public Beta，许可待定”，记录实际时间与验证证据。GitHub实际状态优先；日期化旧记录仅是历史快照。

不用添加 MIT 或其他许可来完成可读 Beta。若所有者以后决定授权，另开许可变更，核对归属。用户业务项目默认仍建议 Private，本框架公开不要求它们公开。
